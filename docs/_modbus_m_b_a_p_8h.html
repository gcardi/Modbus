Detailed Description

Modbus::MBAP — MBAP (Modbus Application Protocol) header framing for TCP/UDP.

Shared, transport-agnostic helpers for building, parsing, and validating the 7-byte MBAP header (Transaction Identifier, Protocol Identifier, Length, Unit Identifier) used by Modbus TCP and UDP. Extracted from TCPIPProtocol so the same framing logic can be reused by both Modbus::Master and a future Modbus::Server implementation.
