Returns the number of register-data bytes following BufferOffset in Buffer.

Validates that the PDU's Byte Count field (offset 1) matches Buffer.Length - 2 and that the data following BufferOffset has an even length. Throws EContextException if either check fails.

void Modbus::PDU::RaiseExceptionIfReplyIsNotValid ( Context const & Context,
TBytes const Buffer,
FunctionCode ExpectedFunctionCode )

Validates a response PDU against the expected function code.

Throws the appropriate EProtocolStdException if the slave returned an exception response (Function Code with bit 0x80 set), throws EContextException if the Function Code does not match ExpectedFunctionCode, or if Buffer is too short to contain a PDU.
