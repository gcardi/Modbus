Validates that RBuffer's MBAP header is a correct reply to LBuffer's request.

Checks header lengths, matching Transaction Identifier, Protocol Identifier == 0, matching Unit Identifier, and that RBuffer's Length field is within the valid range.

◆ WriteHeader()

int Modbus::MBAP::WriteHeader ( TBytes & OutBuffer,
int StartIdx,
Context const & Context )

Writes the 7-byte MBAP header into OutBuffer at StartIdx.

The Length field is computed from OutBuffer.Length - 6, so OutBuffer must already be sized to its final length before calling this function.

Parameters
OutBufferDestination buffer (must be at least StartIdx + HeaderLength bytes).
StartIdxIndex of the first byte of the header.
ContextProvides the Transaction Identifier and Unit (slave) Identifier.
Returns
Index of the first byte following the header (i.e. StartIdx + HeaderLength).
